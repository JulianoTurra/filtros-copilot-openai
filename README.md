# Explorando Filtros de Conteúdo com Copiloto e OpenAI

## Descrição do Desafio

Este laboratório tem como objetivo explorar as funcionalidades do Copiloto e das ferramentas da OpenAI, com ênfase na aplicação de filtros de conteúdo. A ideia é experimentar a geração de conteúdo assistida pela inteligência artificial, testando diferentes configurações de filtros que evitam respostas inadequadas ou indesejadas. O entregável consiste em um repositório organizado com exemplos de uso, prompts aplicados, imagens, logs e anotações dos aprendizados adquiridos.

## Requisitos

- Conta Microsoft com acesso ao Azure AI Studio ou ferramenta similar.
- Permissão para utilizar os serviços da OpenAI.
- Familiaridade com Git, GitHub e Markdown.
- Editor de código para visualizar e editar os arquivos do repositório.

## Passo a Passo

### 1. Acessar o Ambiente e Revisar as Instruções

- **Acesso:** Abra o navegador e navegue até a URL [06-Explore-content-filters](https://microsoftlearning.github.io/mslearn-ai-studio/Instructions/06-Explore-content-filters.html).
- **Leitura:** Revise cuidadosamente todas as instruções, observações e informações sobre o funcionamento dos filtros de conteúdo.

### 2. Explorar os Filtros de Conteúdo

- **Localização:** No menu do ambiente, identifique a seção dedicada aos filtros de conteúdo.
- **Objetivo:** Entenda como os filtros são configurados para prevenir a geração de conteúdo impróprio ou indesejado.
- **Interface:** Observe os controles e configurações disponíveis, como a seleção de parâmetros e níveis de filtragem.

### 3. Configurar e Testar o Filtro

- **Criação do Filtro:** Clique em **Create content filter** (ou opção equivalente) para iniciar a configuração.
- **Ajuste de Parâmetros:** Configure o filtro definindo quais tipos de conteúdo devem ser bloqueados ou moderados. Defina níveis de restrição conforme indicado nas instruções.
- **Teste com Prompts:** Utilize o Copiloto para aplicar prompts de teste:
  - Teste com filtros desativados para visualizar uma resposta “bruta”.
  - Ative os filtros e observe como a resposta é modificada para evitar conteúdo inadequado.
- **Registro dos Resultados:** Documente os resultados, capturando screenshots e anotando as diferenças obtidas com cada configuração.

### 4. Realizar Experimentos com o Copiloto

- **Geração de Conteúdo:** Experimente a criação de diversos tipos de conteúdo usando diferentes prompts.
- **Iteração:** Varie os parâmetros dos filtros e os prompts para identificar como as configurações impactam a saída da ferramenta.
- **Comparação:** Compare as respostas geradas, destacando a eficácia dos filtros e identificando possíveis melhorias.

### 5. Organização e Documentação do Repositório

- **Estrutura dos Arquivos:** Organize o repositório com pastas específicas para cada tipo de conteúdo:
  - `/prompts` – Exemplos dos prompts utilizados.
  - `/imagens` – Capturas de tela e imagens ilustrativas do processo.
  - `/anotacoes` – Logs, comentários e análises dos resultados.
- **README Atualizado:** Mantenha este arquivo atualizado com uma visão geral do desafio, descrevendo o passo a passo, as configurações aplicadas e os principais aprendizados.
- **Comentários e Insights:** Inclua notas sobre dificuldades, descobertas e sugestões para futuros experimentos.

### 6. Concluir e Compartilhar o Projeto

- **Revisão Final:** Revise toda a documentação e os resultados experimentais antes de finalizar o repositório.
- **Compartilhamento:** Certifique-se de que todos os arquivos essenciais estejam presentes e compartilhe o repositório conforme solicitado.
- **Reflexão:** Registre uma conclusão sobre como a aplicação dos filtros de conteúdo contribuiu para melhorar a moderação e segurança nas respostas geradas pela inteligência artificial.

## Conclusão

Ao finalizar este laboratório, você terá experimentado a aplicação e os efeitos dos filtros de conteúdo no ambiente da OpenAI, aprendido a ajustar os parâmetros dos filtros e documentado todo o processo. Essa experiência é fundamental para compreender como prevenir a geração de conteúdo inadequado e aprimorar a qualidade da criação assistida por IA.
